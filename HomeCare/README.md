# HomeCareApp

[English]

Technologies used:

- .NET 8.0 (ASP.NET Core MVC)
- Bootstrap 5 for design and layout

How to run the project:

1. Install the .NET 8.0 SDK.
2. Open the terminal in the project folder and run `dotnet ef database update to create the database`.
3. Then start the application by running the command `dotnet run`.
4. When the application starts, open your browser and go to the address shown in the terminal (for example, <http://localhost:5000>).
